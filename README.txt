MOCKTEST BUILDER
================

Files:
- index.html
- style.css
- script.js

Run:
1. Keep all 3 files in the same folder.
2. Open index.html in Chrome/Edge.

IMPORTANT:
You do NOT need to edit script.js to add questions.

Inside the running website:
1. Set Test Name.
2. Set Time in minutes.
3. Set Correct Marks.
4. Set Wrong Marks / negative marking.
5. Write Subject.
6. Write Question.
7. Fill A, B, C, D.
8. Select correct answer.
9. Click Add Question.
10. Repeat for as many questions as you want.
11. Click Create Test.

You can also Edit/Delete questions before creating the test.

This version stores the test only while the page is open.
A future version can add Save Test / Load Test / multiple tests / login / online database.
